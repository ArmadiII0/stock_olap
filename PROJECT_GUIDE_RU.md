# Краткая карта проекта

Проект показывает учебный ETL/ELT-пайплайн для фондовых данных:

```text
yfinance → staging → core → mart → reports/charts
```

## Где смотреть в первую очередь

- `config/settings.py` — параметры подключения, тикеры, даты и настройки портфеля.
- `scripts/run_all.py` — полный порядок запуска проекта.
- `src/yfinance_loader.py` — загрузка и нормализация данных из yfinance.
- `src/core_builder.py` — создание измерений и факта рынка.
- `src/portfolio_builder.py` — логика отбора бумаг, весов, сделок и ежедневной оценки портфеля.
- `sql/04_create_marts.sql` — аналитические витрины, из которых строятся графики.

## Как читать комментарии

Комментарии добавлены не к каждой строке, а к важным смысловым блокам: где начинается слой данных, зачем нужна функция, почему считается именно такой показатель и где можно менять параметры.

## Что обычно менять под себя

1. В `.env` — параметры PostgreSQL.
2. В `config/settings.py` — список `TICKERS`, период `START_DATE` / `END_DATE`, параметры `PORTFOLIO_CONFIG`.
3. В `sql/04_create_marts.sql` — состав OLAP-витрин, если нужны другие метрики.
4. В `scripts/07_make_charts.py` — набор графиков и внешний вид отчётов.
